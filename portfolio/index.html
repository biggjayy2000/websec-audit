What it does

01

Finds the usual mistakes

Missing CSP and HSTS, session cookies without Secure or HttpOnly, obsolete TLS, .git and .env left in the web root, TRACE enabled, CORS that trusts any origin.

02

Stops before it starts

Resolves the hostname and refuses anything out of scope before the first request. Loopback by default; --allow-private for labs, --authorize for hosts you have written permission to test.

03

Writes something readable

Severity-ranked findings with quoted evidence, why it matters, and the fix. Markdown and JSON out, plus an exit code that works as a CI gate.

A real run

“A finding nobody else can reproduce is just an opinion.” Why each finding carries the bytes that matched, not just a title.

The output

  • Scope guard — six tests, including “public target refused by default”
  • Every check — a clean case and a broken case
  • Reports — ordering, counts, JSON round-trip
  • End to end — one test scans a real socket

Under the hood

Standard library only

urllib, ssl, socket. Nothing to install, which means it runs on any machine that has Python — including a locked-down work laptop.

Checks are functions

Each check takes a context and returns findings. Adding one is a single function, and every one is testable without mocking a network stack.

Scope is enforced in code

The guard resolves the target and runs before the session is created, so a hostname pointing at a public address is refused even if it looks local.

Honest limits

Passive only, one URL per run, no authenticated scanning, and severity is a judgement baked into each check rather than a CVSS score.
